# FigFox 数据保留与删除规则

版本：0.1（内部测试）  
生效日期：2026-07-28

本文档记录产品和工程共同遵守的数据生命周期。它不是面向公众发布的最终法律文本；
公开测试前仍需根据经营主体、部署地区和实际第三方服务商完成法律审核。

## 已确认原则

- 用户输入、参考图和生成结果默认私密。
- 私密内容不用于训练 FigFox 自有模型，也不授权第三方用于训练。
- 公开展示必须由用户主动选择；取消公开或删除后立即停止公开访问。
- 解绑 Google、GitHub 或未来的微信身份不会删除 FigFox 账户数据。
- 注销账户会终止全部会话、解除全部登录身份并进入数据清理流程。

## 保留周期

| 数据 | 保留规则 |
| --- | --- |
| 游客身份 | 创建后 7 天 |
| 游客输入草稿、参考图和结果 | 创建后 7 天 |
| 未配置服务器时的本机草稿副本 | 保留在当前浏览器，直至用户删除草稿或清理站点数据 |
| 登录会话 | 30 天；退出或注销后立即失效 |
| 登录用户历史和图片 | 保留至用户主动删除或注销账户 |
| 用户主动删除的图片 | 立即不可见，24 小时内从主对象存储清除 |
| 注销账户的可识别资料 | 注销时立即解除身份并清空公开资料 |
| 注销后的内部清理记录 | 最多 30 天，用于完成级联清理和故障恢复 |
| 备份残留 | 最长 30 天，随备份轮换消失且不会恢复到在线产品 |

## 删除语义

“立即删除”在产品界面中表示内容会立刻：

1. 从历史列表消失；
2. 停止下载和公开访问；
3. 不再参与任何新的产品处理。

对象存储中的文件进入删除队列，目标是在 24 小时内物理删除。备份是隔离、只读且按周期
轮换的，因此不会逐文件即时修改；删除内容最长可能在备份中残留 30 天。

## 账户注销

用户确认注销后，系统立即：

1. 撤销全部登录会话；
2. 删除已绑定的外部登录身份；
3. 清空头像和显示名称；
4. 将全部私密与公开资源标记为删除；
5. 安排图片在 24 小时内清理；
6. 安排账户内部记录在 30 天后最终清理。

用户随后再次使用同一外部渠道登录时，会得到一个新的空账户，旧账户内容不会恢复。

## 工程执行边界

当前代码已经保存到期时间、删除时间和计划清理时间，并能在用户操作时立即撤销访问。
草稿删除会立即从在线查询和本机草稿列表中移除；参考图作为独立资源继续遵守图片删除规则。
服务器部署后还必须配置：

- 周期性游客内容过期任务；
- 对象存储删除执行器和失败重试；
- 30 天账户最终清理任务；
- 30 天滚动备份策略；
- 删除任务审计日志和告警。
