## 图中模块与当前实现

| 框架图模块 | 代码支持的实际含义 | 展示内容 |
| --- | --- | --- |
| SAM | 提供图片、图标及箭头区域候选；提示词要求先完成全图构建，再按经全图核对的映射替换；不强制使用误检候选 | 同一个实验原图中的三个真实裁片，点击对应原图位置 |
| Relational guidance | 先建立基础框架，再以锚点和邻居描述相对位置；保留包含关系和原有共享布局 | 初稿中上下两个条件框的顺序、共同容器和边缘对齐，切换解释标注 |
| Crop pairs | 基础框向左右各扩展半个框宽、上下各扩展半个框高，裁到画布范围；原图与初稿按相同尺度配对 | 实际生成的初始局部对照对，可显示目标框、放大查看 |
| SVG+ | 原生文字、几何形状与路径，排版后的矢量公式，以及内嵌图像共同存在；不承诺全部矢量化 | 实验 SVG 的内容分层标注，另取真实公式组合展示 |
| Transform Position / Text | 测量实际绘制边界，根据明确范围进行变换或适配；执行后检查容纳、间距及邻居约束 | 真实文字越界案例的初稿与执行后输出，以及过滤后的执行回执 |

SAM 的候选不是完整语义关系推理。关系标注用于解释提示词与真实图结构，并不是自动抽取图或模型日志。SVG+ 分层标注也明确为演示标注。局部修复不等于视觉质量已经通过；未落地问题可进入受请求次数约束的回执跟进。本页没有宣称无限迭代，也没有把 README 中未接通的重新生成分支展示为现有能力。

## 页面实现与边界

五个模块以平级选择器展开，默认关系引导。桌面左侧为实际局部与轻量交互，右侧为模块作用、参照或约束及适用阶段；手机依次阅读图与解释。减少卡片分割和无意义装饰线，紫色线只用于解释真实目标、关系或容器边界。模块切换仅短暂渐显；滚动进入沿用前面章节的轻动效，尊重减少动态效果设置。

新增素材仍由开发服务器的固定文件允许列表读取，不复制到 `public` 或生产包。执行回执接口只输出状态与检查谓词，不暴露完整实验 JSON、路径、提示词或模型响应。生产版本明确标为方法示意，使用手写原生 SVG，并不请求私密案例。没有调用生成或修复服务，没有新增付费实验，也没有发布或提交到远端。

浏览器截图及校验报告放入被忽略的 `frontend/.review/demo/mechanisms/`。
