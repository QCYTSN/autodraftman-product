# 第五部分构思：初稿与修复结果

## 这一部分回答什么

前面已经展示了可编辑结果、原图对照、整体流程和五个支撑模块。第五部分围绕同一张图的初稿与修复输出，展示整套修复流程实际带来的变化。建议标题使用「初稿与修复结果」，说明为「对照同一张图在初稿与修复阶段的差异」。

首版已按这一方向接入本地演示页，位于五个支撑模块之后。采用三个现有案例的实际初稿与修复输出，没有开展新的实验。实现、证据与验证记录见 [第五部分实现记录](figfox-refinement-2026-10-03.md)。后文保留设计依据与后续评测方向。

因此，现有输出足够制作定性的修复前后展示；统一的质量分数、排名和质量费用关系需要后续评测。

## 首版内容与布局

| 区域 | 内容 | 设计要求 |
| --- | --- | --- |
| 章节标题 | 初稿与修复结果 | 沿用当前字号、字体与留白，用直接的方法描述 |
| 案例选择 | 少量代表性案例，优先覆盖文字排版、公式和连接关系 | 按真实可观察的变化选例，先核对效果；每次展开一个 |
| 主体 | 左侧 SVG 初稿，右侧修复输出 | 相同范围与尺度，完整图和重点局部之间可切换 |
| 原图参照 | 可随时查看对应原图 | 让观察者独立判断修复是否忠实于来源 |
| 图注 | 说明原问题、观察到的变化及仍需检查的部分 | 用具体对象和现象，不用「全面提升」等结论 |

桌面两个对照图占主要空间，图注靠近图像。手机按初稿、执行后和说明依次排列，支持放大观察。保持轻量切换及滚动进入效果。图片源文件不改写，展示范围与解释标注属于页面视图。

第四部分解释各个工具如何工作；第五部分选取不同案例，展示整套流程前后的结果。这里不重复 SAM 裁片选择、关系覆盖层或同一个文字越界修复的详细回执。

## 后续定量主图

首选逐样本的配对点图：每行对应同一张原图，灰色点表示初稿，紫色点表示修复输出；数值来自统一评测。点击某行，展开对应的原图、初稿和修复输出。改善与退步都保留，未完成或指标不可用的样本明确记录。

候选评价维度如下，属于待定义、待验证的评测方案：

| 维度 | 需要检查的内容 |
| --- | --- |
| 视觉一致性 | 对应对象的文字、配色、形状和相对位置与原图是否一致 |
| 结构正确性 | 元素是否遗漏，连接端点、方向和包含关系是否正确 |
| 可编辑性 | 预期文字能否独立修改，形状与连接路径能否分别操作，组合与图像的操作范围是否合理 |

这些维度不以 SVG 节点数、执行的程序数或模型自己报告的问题数直接替代。应先固定样本、版本和评价口径，为初稿与修复输出进行一致的标注、操作验证和评分，再绘制数值主图。它能展示完整修复流程的变化，不能单独证明每个支撑模块的独立贡献。

费用与质量散点图、多方法对比、模块消融放到后续实验内容中，分别采用一致的成本口径、共同评测设置和专门的对照实验。第五部分先围绕一个清楚的比较展开。
