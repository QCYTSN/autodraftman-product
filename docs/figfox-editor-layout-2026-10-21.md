# 编辑器布局与控件收口

本轮按实际工作区重新分配空间，保留 FigFox 的白色、紫色视觉系统。范围为当前已接入功能的 UI、控件状态和由新增入口暴露的操作问题；不将其描述为整个 SVG 标准或 SVG-Edit 全功能验收。

## 空间布局

- 顶部只保留撤销、重做、编辑、排列、视图和面板开关，颜色、线宽、透明度统一归入属性页的“外观”。
- 桌面使用独立工具轨、画布、属性栏、底部选择方式与缩放区域。画布不再被浮动顶栏和侧栏覆盖。
- 900px 以下属性栏按需展开，始终提供面板开关与关闭按钮；工具和缩放保留直接入口。
- 编辑区按实际剩余窗口高度伸缩，移除旧的最小高度挤压。属性共用一个滚动容器，修复星形/多边形参数把下方属性裁切的问题。
- 数字参数的长标签与值分行；统一控件尺寸、字号、间距、焦点状态。图层管理收进可展开区域，为对象树留出空间。
- 渐变、图片、源码与形状库弹窗适配窄屏；长文件名和对象名截断显示，控件标签允许换行。

## 功能入口与状态

| 功能 | 当前入口或调整 |
| --- | --- |
| 绘图与扩展工具 | 左侧工具轨及“更多绘图工具”；选星形/多边形自动展示参数 |
| 颜色、渐变、描边、透明度 | 属性 → 外观；线宽 0–99，回车或离焦提交 |
| 字体 | 属性 → 字体，可输入字体族并提供原生常用字体建议 |
| 虚线 | 归一化计算值中的空格、逗号、px；补齐两个原生预设，保留自定义值显示 |
| 粗体和装饰 | 识别数值粗体，按当前状态明确设置 normal/bold；下划线、删除线、上划线都有选中反馈 |
| 图片 | 更多 → 图片或属性 → 替换图片；支持本地文件和 HTTP(S) 图片网址 |
| 网址图片 | 浏览器读取、检查格式与 10MB 上限、解码后嵌入 SVG；不保留会被保存清理掉的远程图像引用；失败可恢复、取消会中止请求 |
| 图片替换 | 仅替换内容，保留位置和尺寸；使用单独撤销记录，不调用会重置固有尺寸的原生 setImageURL |
| 画布预设 | 页面 → 画布预设，以及自定义尺寸 |
| 导出质量 | 页面 → 导出图片 → JPEG / WebP 质量；PNG/BMP 仍为无损格式 |
| 图层 | 图层 → 当前图层 / 管理图层 / 对象树；新建、重命名、合并、移动选区等入口保留 |
| 高级原生设置 | 编辑 → 完整工具，页面 → 文档属性与图像存储 / 偏好设置，继续复用原生控件 |

## 验证记录

- `review:editor-layout`：1440×900 中英文、1024×768 英文、820×700 英文、1280×600 中文、390×844 中英文、320×640 英文。检查页面、属性、图层管理、长标签、星形参数、面板收起、菜单与弹窗；检查实际数值粗体切换、虚线、字体、画布预设、质量参数及导出。
- `review:editor-image-url`：实际 PNG 读取嵌入、替换尺寸、撤销/重做、SVG 下载、请求失败和取消。
- 原有 `review:editor-reliability`、`review:editor-capabilities`、`review:editor-selection` 覆盖保存重开、变换微调、细小文字点选、图层、渐变和原生入口；图层检查按新交互先展开“管理图层”。
- Impeccable 静态检查未报告问题；另进行了独立只读审查，发现并修复数值粗体首次取消失败。

SVG 副本、截图与结果在 `frontend/.review/editor-layout/`；发布版核对在 `frontend/.review/releases/2026-10-21-editor-layout/`。检查使用专门构造的副本，不计入正式样本的 D13/D14/D16。

本轮没有针对实际复杂业务文件重新开展性能测量。文件句柄覆盖保存、原生高级对话框全部组合等未在本轮完成验收，原有功能边界仍保留。
