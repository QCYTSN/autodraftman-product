## 必须明确的适配差异

- Windows 文件锁、旧模块的延迟 POSIX 导入、目录 fsync：平台兼容补丁。
- 输入计数回调：每个新生成请求前增加一次计数请求，生成请求正文不变。计数不可用会停止，因此这是额外的网络依赖；本轮没有实际测试其账号访问权限。
- 网页只开放新图完整重建，不提供上游命令行的消融、外部 checkpoint 参数。非空用户提示词不会悄悄附加到原版 prompt。
- 本地适配增加上传限制、单任务锁、累计预算、进度、幂等提交和一小时任务时限。上游每阶段 900 秒超时保持原值。
- 外部 SAM3 bridge 及其模型运行环境不属于这 1111 个文件；本轮检查了桥接转发代码，未重新执行 SAM。之前失败记录中的 SAM 提取已完成。
