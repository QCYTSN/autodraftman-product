# FigFox 接入与故障恢复复核 — 2026-11-06

## 结论与责任

此前检查覆盖了上游源码、三个生成阶段和合成样例的输入/输出一致性，但没有覆盖完整产品运行条件，尤其是连接模式回退、进程恢复和网页异步状态。将这些检查称为“全面验收”不准确。

历史 Git 对照确认：恢复原版时移除了曾使用的流式/后台连接适配，改回同步等待。最近失败在 G0 或 G1 等待约 61–64 秒、尚未读取到 HTTP 状态行时发生；G1 计数已经成功，阶段超时配置为 900 秒。较早成功请求使用流式或后台方式，不能证明同步方式同样可靠。连接兼容性回退属于此次适配交付的问题。

现有日志无法确认是本机代理、远端节点、边缘网关还是供应商关闭连接。没有抓包或对应时段代理日志，不将推断写成确定根因。

本次修复连接和产品状态，不替换原版推理流程。未提交用户图片、未访问真实输入计数/生成/恢复接口、未运行真实 SAM 推理、未增加预算、未清除预留或重写历史任务。模型生成仍只能由用户手动触发。

| 环节 | 确认的问题或检查项 | 当前处理与证据 |
| --- | --- | --- |
| 上传 | 换图解码过程中可提交旧图 | 同步提交锁与界面状态阻止提交；浏览器延迟解码场景通过 |
| 原图 | PNG/JPEG 保留字节，WebP 同像素转换 | 原件另存，输入格式/字节/像素上限测试保留 |
| 输入计数 | 旧原版保守估算误拒小裁剪 | 同输入实际计数；20 张合成裁剪、边界及计数故障测试通过 |
| 原版一致性 | 不能只看配置和函数名 | 原版入口与真实 worker 比较三个阶段的完整输入、输出 SVG/PNG、操作及未解决问题 |
| 创建请求 | 同步连接断开，无法确认是否已经创建 | 创建前持久化提交标记；返回有效 ID 后立即保存；未知提交不得重发 |
| 已有响应 | 查询断线后缺少可靠恢复 | 只 GET 相同 ID，验证请求/来源/配置/响应哈希；没有新增 POST、计数或预留 |

| 后续阶段 | 查询恢复可能绕过后续预算 | GET 不新增预留；下一未发送阶段仍先检查单图和累计预算；合成零余额场景阻止 POST |
| 重试次数 | GET 查询次数会耗尽新阶段恢复资格 | 准备/新阶段次数单独记录；多次 GET 后仍可在预算允许时继续 |
| 进程异常 | 启动失败、退出或重启丢失费用与恢复入口 | 重建 failure 信息并保留阶段；worker 已写详情不覆盖 |
| 活动进程 | API 重启误把尚在工作的子进程标记失败 | worker 互斥锁识别仍在工作；退出后状态轮询恢复遗留记录 |
| 服务并发 | 多 API 可争用同一任务目录 | 服务全生命周期互斥；第二实例被拒绝，释放后可再次启动 |
| 历史扫描 | 只检查最近 50 条会漏旧活动任务 | 恢复扫描全表；列表显示仍限最近 50 条 |
| 账本 | 非有限/负数等损坏值可能影响预算 | 非法金额停止放行；保留未知费用预留；完成记录与待完成记录分别检查 |
| 本地收尾 | 已取得三次回答，渲染失败仍没有恢复入口 | 已完成响应验证通过后可仅执行本地收尾，验证零额外模型调用 |
| 首次恢复 | 首次历史读取失败后不再尝试 | 独立重试，断线后继续同步 |
| 网页连接 | 后端断开后按钮仍显示可提交 | 禁止新提交、保留已有任务查询，连接恢复后更新 |

| 重复点击 | 创建/恢复重复发送风险 | 提交幂等键、失败 revision、前后端互斥与隔离双击测试 |
| 本地边界 | 公开网页不能直连本地生成 | 回环/来源/请求体限制保留，生产构建不启用本地客户端 |
