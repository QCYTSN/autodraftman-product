## 实现

- 侧栏提供中性“新建任务”、紫色“新建 SVG 画布”、浅紫选中态“我的 SVG”；折叠后保留有名称和提示的图标。顶栏直接打开 SVG，并按活动文档 ID 与名称提供继续编辑。
- 工作台固定在视口内，56px 顶栏、232/68px 侧栏，只有正文及最近任务列表独立滚动。任务和文件集合统一使用最大 1080px 容器。
- 图片任务上传前后均为 3:2 双栏；原图框 280px，图片区 234px、工具栏 44px；要求输入框 200–240px，底栏 64px。文生图无参考图时为全宽输入，有参考图时为 300px + 剩余宽度。输入过程中不播放尺寸动画。
- 文件集合采用最小 240px 卡片和 16px 间距，桌面四列；保留搜索、改名、下载和删除确认。示例创建独立文档。
- `/workspace?view=task|documents` 对应两种主要视图；支持浏览器前进、返回和编辑器来源上下文。原图与流程使用 Dialog，不增加历史记录，关闭后恢复触发控件焦点。
- 侧栏 220ms、Tab 180ms、正文与任务切换约 180ms、视图 260ms、参考图布局 220ms、图片交叉淡入 160ms、Dialog 160ms；减少动态效果下直接呈现最终状态。工作台、加载层和编辑器复用 28px 标志与 20px 字标。

## 数据与文件保护

继续复用原有栅格校验、Blob 存储、SVG 导入清理、IndexedDB 文档和文件句柄机制；未修改数据库版本、API DTO 或 SVG 引擎。任务类型迁移、图片恢复与清理、文档 ID、改名和导出保持原有语义。新建与示例显式创建新 ID；共享操作锁防止重复提交；无效文件和取消选择不创建记录。进入编辑器前保存当前任务，文字或原图本地保存失败时留在工作台。浏览器返回也先保存当前编辑内容，失败则保留编辑器供恢复。

## 本轮发现并修复

- 旧圆形按钮样式误裁原图；移除被替代规则，预览完整保留宽高比，工具栏铺满素材框。
- 窄屏设置弹层越界；约束为面板内展开。
- 快速切回尚未更新的选中 Tab，会被前一次异步切换覆盖；现在以最后一次点击为准。
- 新增活动文档读取暴露旧数据库升级阻塞时的重复请求排队问题；保留失败状态至原请求完成，明确提示关闭旧标签页，验证迁移后文档保留。
- 浏览器返回绕过页面内返回按钮的保存等待；现在共用离开前保存契约，并验证失败后可以恢复。

## 连续操作证据与范围

`browser-session.webm` 为真实 Chrome 会话的 28.28 秒原始录屏。前段包含模式切换、添加/移除参考图、侧栏折叠展开、上传/替换、大图与流程弹层、任务/集合切换、新建画布进入编辑器再返回；后段包含错误恢复与窄屏检查。另通过浏览器解码检查了 3s、6s、10s 起的连续帧，保存在 `motion-frames-*.png`；没有把静态截图拼成录屏。

原生文件选择路径使用受控选择/取消响应与浏览器真实 OPFS 文件句柄验证；没有自动操作系统级文件对话框。中文组合输入以组合事件验证，未自动操作系统输入法候选窗。生成服务继续显示真实未开放状态；未执行付费生成、生产部署或后端改动。

构建仍有既有的大体积 chunk 提示，构建成功。布局扫描仅提示 Tab 指示条的宽度过渡；按本轮既定交互保留 180ms 的小范围指示条动画，不用于输入框或大面积布局。
