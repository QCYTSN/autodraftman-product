# SVG-Edit 接入修复与 FigFox 统一界面

本轮针对 [40bb365 基线审查](figfox-editor-full-parity-audit-2026-10-21.md) 的 A1–A6、B1–B5 实施修复。基准仍是实际安装的 SVG-Edit 7.4.2；本记录不代表 SVG 标准全部特性或全部可选扩展验收。

## 修复与入口

| 原问题 | 本轮结果 | FigFox 入口 |
| --- | --- | --- |
| A1 图片嵌入 / 引用 | 导出读取保存策略与嵌入缓存；缺少缓存时按 CORS 规则读取图片，失败明确提示。HTTP(S) 图片引用重开保留。PNG 等栅格和 PDF 输出先准备嵌入副本。 | 页面 → 图像存储 |
| A2 动态尺寸 | 源码、下载与重开共用响应式设置；导出仅保留 viewBox，内部编辑快照保留固定尺寸。源码弹窗也有开关。 | 页面 / 查看源码 → 响应式 SVG 尺寸 |
| A3 节点状态 | 链接控制点直接读取引擎状态，首击正确切换；原生按钮与 FigFox 状态同步；子路径启停有明确状态。 | 属性 → 路径 |
| A4 单位 | 画布、引擎、标尺和对象字段同步；支持 px/mm/cm/in/pt/pc/em/ex，长度字段可直接输入 2cm、10mm、9px。em/ex 使用引擎实测换算，独立文件尺寸仍用 px 防止查看环境字体改变尺寸。 | 页面 → 单位；对象长度字段 |
| A5 偏好持久化 | 网格、吸附、标尺、单位和编辑背景存入浏览器偏好。原生文档/偏好菜单进入同一个 FigFox 页面面板；语言使用页面顶栏。修复原生 gridcolor 事件遗漏。 | 页面面板；顶栏语言 |
| A6 调色资源 | 复制并发布 13 个原版图片资源及许可证。原生填充/描边入口使用统一的 FigFox 调色弹窗，绕开旧渐变控件的百分比半径、铺展与复合变换显示问题。 | 两套布局的填充 / 描边 |
| B1 高级渐变 | 增加 pad/reflect/repeat、椭圆比例、角度、焦点跟随、拖动控制点与色标。预览采用真实 SVG 渐变，使用对象范围、坐标、透明度和变换。修复 href 继承的渐变参数丢失。 | 填充 / 描边 → 渐变与透明度 |
| B2 高级纯色 | 增加 HSV 数字输入、H/S/V/R/G/B/A 通道选择、原色/当前色比较及恢复，恢复原版 41 色加无色快捷色板。 | 填充 / 描边 |
| B3 文件保存 | 支持文件句柄、保存写回、另存为、Ctrl+S / Ctrl+Shift+S；句柄随浏览器草稿保存。导出副本仍独立保留。不支持文件系统选择器的浏览器使用下载副本，并显示说明。 | 顶栏保存菜单 |
| B4 参数范围 | 恢复 1/2 边及超过 128 的参数，比例不再限 128；保留明确的 12,000 边/角操作上限，超限报错而非静默截断。修复移动后改边数的中心偏移，单点退化形状保留相对中心信息并支持撤销和重开。 | 更多工具 → 星形 / 多边形 |
| B5 大文件重开 | 移除与导出不一致的 5 MB 文件限制，继续执行 12,000 元素复杂度限制及 SVG 安全清理；更新编辑器、工作台和指南文案。 | 打开 SVG / 工作台导入 |

## 界面

沿用 FigFox 白色面板、紫色操作色、原有字体和控件密度。设置收进“页面”，高级渐变使用桌面双列 / 窄屏单列布局，坐标和矩阵按需展开。弹窗内容区独立滚动，底部按钮不覆盖字段；单位放在字段角标，避免每个数字多占一行。原生调色与偏好入口进入相同界面。

## 已执行验证

Chrome **155.0.8059.40**。全部使用合成 SVG 副本，不改正式样本；修改后的导出文件保存在对应 `.review` 目录。

- `npm run build:pages`：类型检查及发布构建通过。
- `scripts/editor-parity-repair-check.mjs`：在发布构建 `http://127.0.0.1:4175/figfox` 上 **14/14 通过，无页面异常**。覆盖 13 张调色资源加载解码、单位输入、节点状态、偏好刷新、动态源码/导出、嵌入/引用图片、渐变拖动与保存、HSV 和全部通道、继承渐变、退化形状移动与重开、超过 5 MB 的导出重开、文件保存、嵌入失败反馈、中文/英文和 320 px 界面。
- `review:editor-color`：6 项通过，连续调色、HEX/RGB/alpha、取消、撤销、色标、导出重开及键盘操作无回归。
- `review:editor-save`：3 项通过，包括本地存储失败时仍导出实际修改并报告失败。
- `review:editor-reliability`：8 项通过，包括延迟启动、缩放、旋转文字移动、输入焦点、原尺寸插入、形状属性及 em/ex/mm 保存重开。
- 代码审查发现并修正：形状中心缓存过期、响应式源码与导出不同步、链接渐变丢失继承属性。复查未发现这三处仍有阻断问题。

## 验证边界

- 文件系统检查使用浏览器 OPFS 提供的真实 FileSystemFileHandle，验证写入、关闭、读取与 IndexedDB 句柄恢复；系统文件选择窗口由测试替代，未自动操作真实磁盘的系统对话框。下载回退另经实际下载与重开验证。
- 5 MB 边界检查使用少量 SVG 对象和大载荷，验证文件入口一致性，不是复杂大图性能压力测试。
- 12,000 元素、12,000 边/角上限和导入安全过滤仍是产品边界。mask、clipPath、pattern、复杂滤镜和 symbol 资源管理等专用面板仍未被本轮扩展为完整可视化编辑器。
- 未执行正式 sample-0077 等样本的 D13/D14/D16，不将合成检查记为正式样本通过。
