# FigFox 产品界面重构

日期：2026-10-04。范围为展示页发布、定价、指南、工作台、SVG 编辑器外观与本地使用体验。生成内核和公网后端不在本轮接入范围。

## 页面结构

展示页作为 `/` 门面，产品导航保留 `/docs`、`/pricing`、`/workspace` 三个主要入口。`/editor` 是工作台进入的独立编辑界面，也可直接访问。

统一使用给定 FigFox 标志、Noto Sans SC 和 Google Sans Flex。产品页延续展示页的白色、紫色与蓝色搭配，减少装饰性边线。工作台保留较紧凑的操作密度，手机端采用纵向布局和草稿抽屉。

定价保留 Sketch、Folio、Atlas 原名称、图标和金额，重新安排套餐信息、计费切换、方案比较与常见问题。所有订阅入口说明尚未开放，不创建支付流程。

指南按当前可用功能编写，目录有滚动定位，提供可直接打开编辑的真实实验示例与常见问题。定价页明确本地 SVG 编辑当前免费，拟定套餐供后续生成服务使用。

## 保留与改善的编辑能力

继续使用现有 `SvgEditHost`、`FigFoxEditorChrome` 和 SVG-Edit 的编辑命令与撤销栈，没有替换编辑内核。修改集中在品牌外观、工作区域、入口和状态：

- 可直接创建 1280 × 720 空白 SVG，或导入已有文件。
- 用 IndexedDB 分别保存多个文档，返回页面及刷新后恢复实际编辑内容；旧版单文档记录自动迁移，旧标签页阻塞迁移时提示关闭后刷新。
- 重要状态变化前尝试立即保存，不只依赖延迟保存。
- 本地恢复继续清理脚本和外部引用，并检查元素数量；不会因编辑后的文档超过文件选择的 5 MB 限制而拒绝恢复。
- 无效导入保留已有文档；新建画布另存为文档，原文档保留。
- 工作台提供缩略图、导入、新建、真实示例、搜索、改名、下载和删除；原图预览可与文档列表切换。
- 手机端将当前可用的 SVG 操作放在生成准备表单之前，桌面端保留左右两栏。
- 工作台草稿在快速离开页面、新建或切换时保留最近输入。
- 浏览器草稿存储失败显示真实失败状态，不显示已保存。
- 草稿抽屉、删除确认和新建文档确认支持焦点管理与键盘关闭。

导入文档的字体、颜色、图形关系不随 UI 主题修改。展示页的特殊指针不进入产品编辑区域。

## 登录和 Docker

后端已包含 FastAPI、PostgreSQL、私有 S3 兼容对象存储、会话和额度账本，以及 Google／GitHub OAuth 的状态校验与 PKCE。它们是后端实现，不能由静态发布页面替代。

现有 Docker Compose 为开发配置，可在一台机器上运行 API、数据库和对象存储。Docker 本身不提供公网服务器、域名或 HTTPS；要公开账户功能仍需实际托管和 OAuth 配置。本轮没有启动或修改生成服务，也没有配置公共 API。

因此未配置 API 的页面不会创建假游客身份，不显示虚构额度，不上传参考图。参考图只提供浏览器预览，刷新后需重新选择。已有账户、上传与草稿 API 接口继续保留，等待后续部署。

## 验证与发布

产品操作检查覆盖三套餐、计费切换、订阅状态、FAQ、登录状态、本地草稿、参考图、指南滚动、实际 SVG 编辑和导出、文档恢复、错误导入、存储失败及手机键盘操作。

排版检查覆盖十个路由、中英两种语言、320／375／414／768／1280／1440／1920 七种宽度。正式构建的检查同时验证 `/figfox/` 子路径、页面刷新、实际产品操作、多文档保存和完整展示页交互；只检查剩余页面能否运行不足以证明发布完整。

已移除开发专用素材读取插件，展示案例从公开素材目录随构建发布。三组可编辑案例、原图滑动对比、五个支撑模块、三组初稿与修复对照和六张原图选览在开发与正式版中保持一致。只有逐样本评分、方法比较、消融和效率四张尚无数据的图表使用占位。发布遗漏与验证记录见 `figfox-completion-audit-2026-10-04.md`。

只从本仓库的已知提交构建，再将 `frontend/dist` 发布到 `QCYTSN/figfox` 的 `site/`。发布镜像的 `_release.json` 记录源仓库、提交与构建时间。公网地址为 `https://qcytsn.github.io/figfox/`。

当前限制：多文档保存仍属于当前浏览器，不跨设备同步，重要成果需导出。订阅、OAuth 公网服务、文生图与图转 SVG 仍待后续接入。未完成的评测图表使用占位，不宣称已有评价结果。
