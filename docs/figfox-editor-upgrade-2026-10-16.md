# FigFox 编辑器补齐与优化

日期：2026-10-16。范围：产品仓库的 `/editor`，基于本地 SVG-Edit / svgcanvas 7.4.2。保留 FigFox 界面及现有 8 个扩展，不改动研究项目或正式输出 SVG。

## 功能

- 恢复原生选择、修改、缩放、组内编辑和扩展事件链，避免 FigFox 的监听器覆盖底层处理。
- 导出直接读取当前画布的独立快照；属性提交在导出点击前生效。重新打开同一份 SVG 会建立新的文档实例，不会因正文去重而停在加载状态。
- 快照不退出路径或组内编辑，剔除组内编辑的临时调暗及交互屏蔽；保留进入组之前的样式，退出时恢复。
- 圆、路径、组及多选的 X/Y/W/H 按画布上的实际包围框变换，避免向圆写入无效的 width 属性。
- 文字修改保留 tspan / textPath 子节点，支持撤销和重做；补回上下标、字距等安全属性。修复双击文字后原生输入框无法获得焦点的问题。
- 新增线性/径向渐变、多色标、独立填充与描边透明度；渐变修改作为一个撤销步骤。回显现有渐变、混合填充和引用填充。
- 新增真正的图层创建、重命名、复制、删除、排序、合并及跨图层移动。选择其他图层的对象时同步切换活动图层。
- 新增节点坐标和线段类型、形状专用参数、字距/词距/文字长度、中间标记、ID/Class、解除 use 引用等入口。
- 新增页面尺寸、单位、网格吸附、偏好设置和 PNG/JPEG 图片导出。原生布局的 PNG/JPEG/WebP 同样使用干净快照下载。
- 命令失败显示明确提示。本地存储失败仍允许导出实际修改后的文件。

## 性能

- 同一帧合并状态通知，相同状态不重复发送。
- 只有结构及相关属性变化才重建对象树；纯选择操作发送轻量状态。前端保留未变化的树引用。
- 对象列表只渲染可见区域及少量预加载行，支持折叠和搜索。
- 全文序列化延后到交互间歇；拖动期间不反复生成完整 SVG。显式导出始终读取最新快照。
- 数值输入使用草稿，在确认/失焦时提交；文字输入合并短时间内的修改并兼容输入法。
- 回传去重最多保留 3 份 SVG 正文，原来为 24 份。

以上是已实现的开销削减，不是帧率或延迟基准结果。本轮没有压力测试，也没有宣称所有复杂文件都不会卡顿。

## UI

- 侧栏整理为“属性 / 图层 / 页面”。
- 提供“完整工具”入口和返回按钮，恢复原生工具与上下文控件的可访问性。
- 组内编辑提供独立的退出入口。
- 窄屏保留撤销、重做、缩放和面板按钮；底部工具栏可横向滚动。
- 延续当前 FigFox 紫色、浅色面板及字体体系。

## 边界

这次补齐的是前次审查识别出的接入问题、常用编辑能力与界面入口，不等同于实现 SVG 标准的全部内容。

- 公式和表格仍按 SVG 对象编辑，没有 LaTeX 或电子表格式的语义编辑器。文字分段保留不等于完整富文本排版系统；沿路径文字保留有实现，但未逐场景验收。
- mask、clipPath、pattern、复杂滤镜链及 symbol 管理仍没有完整的专用可视化设计器。源码入口不能算作这些功能的 UI 覆盖。
- 脚本、动画、foreignObject 和外链内容继续受导入规则限制；导入上限仍为 5 MB / 12,000 个元素。
- 本轮重点验证 SVG 与 PNG，未把原生菜单中其余格式或所有原生工具标记为逐项验收完成。
- 文本显示和位图输出仍依赖可用字体。没有新增字体嵌入或字体转轮廓功能。

## 代码位置

- `frontend/public/svgedit/figfox-bridge.js`：事件、命令与状态调度。
- `frontend/public/svgedit/figfox-features.js`：快照、文字、变换、渐变、图层及图片输出。
- `frontend/src/components/editor/`：属性、图层、页面、渐变和响应式界面。
- `frontend/src/features/product/ProductSvgEditorPage.tsx`：打开、保存及显式导出。
- `frontend/scripts/editor-capabilities-check.mjs`：本次改动的定向回归。

原生压缩 bundle 保持原样；兼容修复集中在独立适配文件，后续升级 SVG-Edit 时需复查。
