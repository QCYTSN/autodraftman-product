# FigFox 展示页与产品页补全

用户指出两边都有遗漏后，重新对比开发页面、正式构建和实际线上页面。此记录取代先前将完整实验案例限定在本地的发布假设。

## 展示页的发布遗漏

原发布逻辑以 `import.meta.env.DEV` 判断是否显示案例。结果是第一部分可编辑 SVG 和第二部分原图滑动对比被隐藏，第四部分改为示意图，第五部分修复对照被移除，六张样本原图被占位图替换。此前的排版和操作检查只证明剩余页面能运行，没有证明发布内容与已设计页面一致。

现在开发与正式构建使用同一个静态素材目录，不再从实验仓库临时读取。发布保留三组可编辑 SVG、原图对比、给定架构图、五个支撑模块、三组修复对照和六张样本原图。没有评测数据的四张图表继续显示用户要求的「占位」。

`frontend/public/assets/demo/cases/manifest.json` 记录 21 个选定文件的来源、大小和校验值。图像、初稿和最终 SVG 保留原始字节；用于说明修复的回执单独提取五类显示字段，标记为派生文件。原始实验目录、提示词、模型响应和完整运行日志没有复制进入产品仓库。没有重新运行生成模型，也没有手工修改实验 SVG。

## 产品页的使用缺口

原工作台能保存描述草稿，但 SVG 编辑器只保留最近一份文档。现在「我的 SVG」提供独立文档保存、缩略图、搜索、导入、新建、示例、改名、实际下载与确认删除。打开卡片会恢复对应文档；修改、新建或删除不会覆盖其他文档。原单文档数据库迁移到多文档存储，旧标签页阻塞迁移时给出可操作提示。

原图预览与文档列表可以切换。工作台输入、我的 SVG 和原图预览分别提供独立视图，桌面保留草稿侧栏与居中的输入区，手机使用可关闭的历史抽屉。描述草稿与 SVG 文档分别管理，文件仍只在当前浏览器保存。

指南加入真实实验示例的编辑入口、文档保存说明及格式、字体、文档缺失和存储失败的处理方式。定价保留 Sketch、Folio、Atlas 的图标、名称和原有金额，补充当前免费的本地编辑入口，并展开拟定套餐内容及实际可用功能的区别。

## 验证方式

`review:product` 验证既有编辑核心、撤销重做、导出、旧文档恢复、失败状态和手机操作。`review:documents` 验证多个文档互不覆盖、搜索、改名、删除、原图切换和数据库迁移。`review:showcase` 验证完整章节、真实交互、发布素材清单与未完成图表的位置。

`review:pages` 在正式构建的 `/figfox/` 子路径运行上述操作检查及页面刷新检查，防止只在开发环境正确。通过后从已提交的源版本发布，等待 Pages 部署，再对实际线上版本复查。

本轮正式构建检查通过：10 个路由刷新、21 项产品操作、12 项多文档与迁移操作、8 组完整展示交互及 21 个素材文件校验。另完成十个路由 × 中英双语 × 七种宽度的 140 组布局检查；调整手机内容顺序后再检查工作台和指南的 28 组布局。检查中未发现浏览器错误；静态功能不请求生成或账户 API。

登录、订阅、图像生成、图转 SVG 和云端文件保存仍按既定范围留待后续服务接入。Docker 开发配置不能代替公网托管；本轮没有创建假身份、假额度或模拟生成结果。

## 公开网页发布补充

用户要求先保留授权内测方案，先将网页完整上线。方案保存在 [授权内测记录](research/figfox-private-beta-deferred-2026-10-04.md)，本轮不启动内核、登录服务或付费任务。

补齐公开版反馈入口：填写内容后打开 `QCYTSN/figfox` 的 GitHub Issues 草稿，由用户在 GitHub 确认发布。明确说明公开性与 GitHub 账号要求，不采集联系邮箱，不显示虚假的提交成功或反馈编号。支持复制全文、当前标签页草稿恢复及双语切换；超出 URL 长度范围的正文改用复制后粘贴，不截断内容。浏览器拒绝剪贴板时选择正文并提示手动复制。

隐私、条款与内容规则先说明当前浏览器内处理、本地保存与删除、公开反馈及未开放的登录和生成服务，已有在线服务规则明确标为后续草案。公开版不展示容易误解为实际生效的云端清理数字。

本次发布验证包括 11 个直接路由与刷新、原有 67 项产品与展示操作、6 项公开反馈操作、3 项导出保存操作，以及反馈与三页规则 × 中英双语 × 七种宽度的 56 组布局。公开反馈外链在操作测试中被拦截检查，没有实际发布测试反馈。发布后再对真实站点核对版本、路由、素材和操作；实际源版本由线上 `_release.json` 记录。

实际线上复查发现编辑器导出后立即刷新可能先于 500 ms 自动保存完成。导出现在先等待本地事务提交，再提供下载；保存失败仍允许导出当前修改，并保留真实的失败提示。没有修改 SVG 编辑内核。独立检查确认下载前已提交实际编辑的文档、立即刷新可恢复，以及浏览器写入失败仍能下载正确文件。

## 登录页衔接

进入和离开独立登录页时，页面轻淡化切换，Logo 连贯移动，鼠标单独保留。标题、表单和左侧图形分次淡入并上移 12 px，最长入场时间为 475 ms。浏览器前进、后退和中途切换共用同一导航处理，较新的操作取消尚未完成的过渡。工作台在登录页后继续保留描述草稿和本地图片；登录页不创建身份或提交任务。

支持页面过渡的浏览器使用原生 View Transitions；其他浏览器直接导航并保留内容入场。系统要求减少动态效果时，两种动效都关闭。独立操作检查覆盖真实过渡、前进后退、中断后再次进入、减少动态效果和手机端降级；逐帧检查 135 ms、250 ms 及结束后的画面。正式构建的 11 个路由和 76 项既有操作检查通过，登录页的中英双语与七种宽度共 14 组布局检查通过，无浏览器错误或账户、生成 API 请求。

## 工作区与编辑器衔接（2026-10-05）

「当前草稿」「我的 SVG」及原图预览使用约 280 ms 的内容区过渡，上方导航和历史侧栏保持原位，选中按钮的背景与文字颜色轻变化。页面过渡由同一个导航处理管理，快速连续点击会取消尚未完成的切换；不支持 View Transitions 时，使用短淡入和 5 px 上移。减少动态效果时直接切换。

进入 SVG 编辑器先显示独立加载画面：紫色路径逐步绘出，控制框和等待点轻变化。提示依次对应实际的界面模块加载、本地文档读取和画布准备；只有空文档界面可用或 SVG 实际加载完成后才显示编辑器。快速加载时保留 420 ms 的短衔接，随后用 180 ms 淡出加载画面，避免一帧闪烁。加载中的编辑界面仍按正常尺寸初始化，暂不可交互；加载画面提供返回工作台的入口。模块加载失败会停止循环动效并提供重新加载；画布报错或 15 秒未响应时解除遮挡，显示真实错误和返回入口。

从工作台进入编辑器期间保留草稿和原图的状态，离开工作台界面时不保留隐藏表单和对话框。返回后重新读取 SVG 列表，显示新保存的文档。独立检查覆盖视图微动效、快切、真实加载等待、中途返回、再次进入、草稿和原图保留、登录衔接、手机降级、减少动态效果、初始化报错及无响应；另检查模块失败时中英双语在 320 px、1440 px 下的恢复操作。工作台和编辑器的中英双语、七种宽度共 28 组布局检查通过。既有原图预览检查改为等待实际视图出现，文件列表的截图等待过渡结束后再拍摄。

最终正式构建的 11 个路由及 76 项既有操作再次检查通过，包括 SVG 编辑、撤销重做、导出保存、文档管理、展示交互、鼠标指针和公开反馈。正常操作无浏览器错误或账户、生成 API 请求。
