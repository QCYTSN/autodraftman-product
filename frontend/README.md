# FigFox Frontend

这是 FigFox 的本地产品前端，包含中英双语首页、生成工作台、登录选择和定价页。
游客身份与额度已连接本地 FastAPI 和 PostgreSQL。

## 本地运行

```powershell
cd D:\Github_Ku\autodraftman-product\frontend
npm install
Copy-Item .env.example .env
npm run dev
```

默认访问地址：

- 首页：`http://127.0.0.1:5173/`
- 工作台：`http://127.0.0.1:5173/workspace`
- 定价：`http://127.0.0.1:5173/pricing`

## 当前实现范围

- 首页为独立演示页，提供真实 SVG 案例的拖动、改字、恢复、原图对照、缩放和下载，以及方法说明和工作台入口。
- 本地案例由开发服务从同级 `FigFox-926` 的明确文件清单中读取，不调用生成 API；实验原图和结果不会进入正式构建。正式构建保留方法图与实验图表占位。
- 中文界面使用 Noto Sans SC，英文和数字使用 Google Sans Flex；案例文档保留自身字体。
- 标题和实验图首次进入视野时轻微渐显；导航当前章节底色、顶部背景与阴影持续响应往返滚动，首屏保留轻微滚动位移。减少动态效果设置下关闭位移与过渡。
- 演示页使用紫色小圆点指针，按钮上展开为椭圆，真实放大入口上显示「放大」。位置直接跟手，仅形状轻微回弹；SVG 编辑、对比滑块、文本选择、弹窗、触控与减少动态效果／高对比度设置下恢复原生指针。
- 本地第五部分对照三组实际初稿与修复输出，可切换局部或完整图、参照原图、放大查看，并返回案例中选中对应元素；实验视觉验收仍待完成。设计与证据见 [实现记录](../docs/research/figfox-refinement-2026-10-03.md)。
- 第六至第九部分展示样本与候选评价维度、方法比较、模块消融，以及质量与费用／耗时；第五部分还预留逐样本配对图。缺数据的图表为白底「占位」，本地样本区使用六张现有原图，正式构建样本区也使用占位。见 [后续展示记录](../docs/research/figfox-research-sections-2026-10-04.md)。
- 工作台支持文字生成、文字加参考图两种模式。
- 参考图通过短期签名地址直接上传到私密对象存储，并显示真实进度。
- 后端会再次验证图片格式、文件大小和像素尺寸；取消和失败都有明确状态。
- 点击生成时可以创建或恢复真实游客身份。
- 游客的一次免费额度由 PostgreSQL 账本保存，不再由前端伪造。
- Google、GitHub 登录方式由后端配置接口决定；没有密钥时不会显示假入口。
- 正式用户可以查看已绑定登录方式、添加另一种登录方式、解绑和退出。
- 游客登录后，其额度和已上传资源会迁移到正式账户。
- 生图内核尚未接入；当前不会伪造生成任务，也不会扣除真实额度。
- 工作台的生图历史、结果图下载、公开状态和定价仍为 UI 原型；首页案例下载会导出当前浏览器中实际编辑后的 SVG。
- 中英文可随时切换，语言偏好保存在浏览器。

## 检查

```powershell
npm run build
```

可以直接运行视觉检查（脚本会临时启动独立的本地服务）：

```powershell
npm run review
```

该检查会验证主要页面在桌面和手机尺寸下是否出现横向溢出。

演示页的设计依据、素材来源和本轮验证范围见 [设计记录](../docs/research/figfox-demo-design-2026-10-03.md)。
