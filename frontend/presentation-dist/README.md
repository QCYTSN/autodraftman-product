# FigFox Architecture Demo V2

Double-click FigFox-Architecture-Demo-V2.html. All resources and the Figtree font are embedded. The legacy filename contains the identical V2 artifact.

English by default; ?lang=zh selects Chinese. Arrows/PageDown/PageUp: scenes; Home/End: opening/editable; 1/2/3: stages; hold B: temporary Before; F: fullscreen; D: details. Menus provide mouse equivalents. Edit confirms with Enter, cancels with Escape, and SVG exports the actual document.

See ../../docs/figfox-presentation-visual-v2.md and its linked script/review for provenance, commands and acceptance. Font license included in the HTML and Figtree-LICENSE.txt.
